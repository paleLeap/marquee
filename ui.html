Listing sites

Eventbrite, AllEvents and Meetup are read directly, day by day: this is where the small, niche and one-off things are. Reading is free. Every new event is then filed and rated by a quick Claude run (Haiku, about a cent per hundred events), which drops job fairs, seminars and ads, and marks the standouts ✦.

Ticketmaster

Concerts, sports, theatre and family shows, with ticket prices when the seller lists them. It needs a free key: sign up at developer.ticketmaster.com, then copy the Consumer Key from My Apps and paste it here. Without one, Marquee still works from the web scan.

refresh every hours

Web scan

Claude Code searches the web, one search per line below, four at a time. Each takes a few minutes and uses about $1.50 of Claude usage on Sonnet, so untick what you never want. Every search is told what is already on the list, so a rescan brings new things. Finds stay until the event is over. The scan button at the top does not run these; they run on their own schedule or from here.
